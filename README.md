# Quill — Markdown Reader

A simple browser app for writing and reading markdown with a live preview.

## Run

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Features

- Live markdown → HTML preview
- Split / Edit / Read views
- Open `.md` files from disk
- Drag and drop files onto the window
- Sample document to get started
